Connexion

Pour modifier le catalogue, collez votre clé d'accès GitHub. Elle reste enregistrée uniquement dans ce navigateur, sur cet appareil.

Comment obtenir ma clé ? (à faire une seule fois)
  1. Connectez-vous à GitHub, puis ouvrez cette page de création de clé.
  2. Token name : écrivez Gestion Smedicalis. Expiration : choisissez la durée la plus longue.
  3. Repository access : choisissez Only select repositories, puis sélectionnez Smedicalis-boutique-.
  4. Permissions → Repository permissions → Contents : choisissez Read and write.
  5. Cliquez sur Generate token, copiez la clé qui commence par github_pat_ et collez-la ci-dessus.

Ne partagez jamais cette clé : elle permet de modifier votre site.
